# VHTR Design Project

A theoretical **Very High Temperature Reactor (VHTR)** design developed iteratively as a living document.

## Concept

A helium-cooled, graphite-moderated reactor using TRISO fuel particles, targeting a core outlet temperature of **≥950 °C**. The primary mission is to deliver carbon-free high-grade heat for:

- Thermochemical hydrogen production (e.g. sulfur–iodine cycle)
- High-temperature industrial process heat (steel, cement, petrochemicals)
- High-efficiency Brayton-cycle power generation (as a secondary use)

## Design Heritage

This design draws on lessons from:
- **HTTR** (Japan, 30 MW, 950 °C achieved 2004)
- **HTR-10** (China, 10 MW pebble bed)
- **GT-MHR** (General Atomics, prismatic block)
- **NGNP** (US DOE Very High Temperature Reactor program)
- **X-energy Xe-100** (modern pebble-bed SMR)
